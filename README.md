# Band Name Generator

A simple Python beginner project that generates a band name by combining the name of the city you grew up in with the name of your first pet.

## Features

- Takes user input
- Combines two strings to create a band name
- Demonstrates basic Python concepts:
  - `print()`
  - `input()`
  - Variables
  - String concatenation
  - `.capitalize()` method

## Example

```
Welcome to the Band Name Generator!

What was the city you grew up in?
lahore

What was the name of your first pet?
buddy

Your band's name should be: Lahore Buddy
```

## How to Run

1. Make sure Python is installed.
2. Save the code as `main.py`.
3. Open a terminal in the project folder.
4. Run:

```bash
python main.py
```
